Administration du blog

Publier sans toucher au code.

Cette interface est préparée pour devenir ton espace de publication : titre, catégorie, résumé, contenu puis publication. Le design public du site ne change pas.

Dernière étape nécessaire : connecter cette interface à ton hébergement ou à un dépôt Git pour que le bouton « Publier » puisse réellement créer les fichiers sur le serveur. Sans cette connexion, un navigateur ne peut pas modifier tout seul les fichiers publics de ton site.

Fonctionnement final

  1. Tu ouvres /admin/.
  2. Tu écris le titre, le résumé et le contenu.
  3. Tu cliques sur Publier.
  4. La nouvelle URL est créée dans /blog/.
  5. La carte apparaît automatiquement sur l’accueil.
  6. Le sitemap est mis à jour automatiquement.
